Overview

This project is a simple rule-based chatbot developed using Python. The chatbot interacts with users through the command line and responds to predefined questions and greetings. It uses conditional statements to match user inputs with appropriate responses and continues the conversation until the user decides to exit by typing "bye". This project is ideal for beginners who want to practice Python fundamentals and build interactive applications.

Features
Interactive console-based chatbot
Predefined responses for common questions
Greeting and farewell messages
Handles unknown inputs gracefully
Continuous conversation using loops
Simple and beginner-friendly implementation

Technologies Used
Python 3

How It Works
The chatbot welcomes the user.
The user enters a message.
The program checks the input using conditional statements.
A predefined response is displayed.
The chatbot continues running until the user types "bye".
Supported Commands
User Input	Chatbot Response
hello	Hi! Nice to meet you.
how are you	I am fine, thanks for asking!
what is your name	My name is Python Chatbot.
who created you	I was created using Python programming.
what can you do	I can answer simple predefined questions.
tell me a joke	Why do programmers prefer dark mode? Because light attracts bugs!
thank you	You're welcome!
bye	Goodbye! Have a great day.
